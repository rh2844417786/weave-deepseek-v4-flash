Approved scope: observe native SGLang execution and routed/shared behavior before selecting a throughput optimization. Design: `docs/superpowers/specs/2026-10-20-native-p0-design.md`.

1. Add CUDA external-event sampling and aggregate grouping reads after completed B32 replays. Test cadence, event freshness, interval accounting and privacy with CPU fixtures. Add an offline four-rank synthetic two-stream graph/CUPTI smoke.
2. Pin native SGLang source identities. Wrap original B32 capture calls without replacing computation; expose actual path, shared TP configuration and Marlin call metadata. Wire opt-in launch flags and graph observer.
3. Collect one private Torch/CUPTI replay trace and publish only actual kernel resource records. Parse the pinned Marlin template and map all 86 routed calls across 43 layers.
4. Add native-only controller, checkpoint attestation, smoke validation, graph coverage and cross-rank evidence summary. Preserve old GPQA modes, data/window semantics, cleanup and whitelist export.
5. Update objective documentation and server prompt. Run focused CPU regressions, independently review measurement/runtime risks, commit and push. Server CUDA execution remains pending and must be reported separately.

The first diagnostic uses C32 and a 1200-second native load. No numerical error gate, candidate-compute prerequisite or CTA-budget modification is introduced.
