# Fixed-prefix native/P0 diagnosis

Approved scope: continue the P0 generation discrepancy investigation with short identical-prefix decode comparisons, native repeatability, separated event/buffer interventions, and a native kernel trace without inserted stage events. No numerical/agreement threshold; server remains GitHub-only offline with existing v0.5.17 image and readonly model.

Use first32 pinned GPQA requests (6059 input tokens total), default8 output positions: prefill prediction plus7 decode predictions. One atomic batched /generate request, ignore_eos=true only for this bounded computation probe. Record native seed continuation privately, then teacher-force that same continuation in all measurement arms: native_a, native_b, p0_full, p0_events, p0_buffers. All arm measurements use the same metadata processor and out-of-graph logit snapshots. Warmup/flush, runtime/source identity, graph replay and actual B32 coverage remain required.

Implement a pinned ModelRunner.sample context wrapper and a serialized no-import-at-module-load CustomLogitProcessor-compatible callable. The processor receives original logits before forcing; validates batch32, row mapping, per-row position/seq_len and actual previous input token; saves CPU logits privately; then masks/selects the prescribed teacher token before the native sampler and ngram state update. Do not override ModelRunner.sample's returned token afterward. Per-rank scalar proof plus private CPU Torch tensor files; CPU comparison runs inside existing image. Raw tokens/logits stay under work-root; public output is aggregate differences, commitments and source/coverage evidence. Logical KV position controlled; physical pool/cache addresses recorded as commitments, never misrepresented as identical KV numerical contents.

Native_a phases: warmup, seed8, flush, forced measurement8, flush, native trace2. Other fresh service arms: warmup, flush, same forced measurement8. P0 intervention modes preserve old default full behavior; isolated probe disables runtime P0 readback, changes event insertion and grouping retention independently. No extra stage events in native trace; capture one decode through Torch/CUPTI outside capture and keep raw trace private.

Control runtime mutation via opt-in flags only, exact source pins for native sampling/model interfaces, explicit private paths under work-root. Five fresh services sequential on one GPUQ allocation, budget extendable. Compare native_a/native_b first, then each P0 arm against native_a; any finite differences complete normally. Fail only malformed input/coverage/source, nonfinite original logits, runtime or cleanup errors. This delivers a diagnostic, not a claimed root-cause fix or throughput gain.
