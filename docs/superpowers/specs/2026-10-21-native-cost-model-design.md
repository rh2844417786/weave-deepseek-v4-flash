## Model
For every batch1..32 and each structural MoE class (hash-vs-learned topk, shared TP1/config, expert weight shapes/dtypes), calibrate the first representative layer using real loaded checkpoint weights and the native MoE forward. Grouping is native. Use six deterministic synthetic activation/input-ID patterns routed by the actual native gate/topk: four distinct spread patterns and two repeated-row patterns. Topk6/E256/EP4 and previous expert row-count observations motivate covering spread versus concentrated/padded work; actual descriptors are measured, never assumed. The separate GPU validity probe explicitly covers empty/heavy local routing. Runtime uses current actual routing, not synthetic patterns. Held-out patterns use distinct route distributions/expert IDs.

Candidates ordered [(8,8),(8,4),(8,2),(4,8),(4,4),(4,2),(2,8),(2,4),(2,2)], where x means x/8 of candidate physical launch grid. Each role caps workers by available tile iterations. Inputs: [local routes, active experts, padded local blocks, sum of squared expert row counts, max expert rows], plus exact batch/role GEMM geometry and class identity. A bounded single-CTA planner per MoE layer gathers the stats once from existing grouping, searches nine candidates with nearest-two measured workload anchors using normalized L1 distance, writes a pair to a persistent plan buffer. Both native kernels consume this plan, so cost mode no longer scans full grouping in every CTA/warp. Empty-local work has zero active workers but still executes one recorded logical call. Original heuristic remains an explicit mode and is never a cost fallback.

Measured surface: each anchor/candidate stores features5 + full_moe_us + fixed_planner_us + search_planner_us (row width8). Prediction is inverse-distance nearest-two interpolation of full_moe_us - fixed_planner_us + search_planner_us. All units microseconds; negative noise-corrected values must not be silently accepted. Full MoE samples include stats planner; replacement accounts for added search. Record raw repetitions, medians/stddev/range, CUDA-event measurement overhead, separate gate/up/down component measurements (not used as independent objective), and complete independent validation errors/regret without a threshold.
